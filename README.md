<h2>📌 About The Project</h2>

<p>
  TruthLens AI is an AI-powered fake news detection platform built as a practical
  software development project. It combines a React.js frontend with a Python
  FastAPI backend and uses Machine Learning and NLP techniques for content analysis.
</p>

<p>
  The project also includes user authentication, verification features and history
  tracking.
</p>

---

<h2>✨ Features</h2>

<ul>
  <li>🔍 <b>AI Fact Verification</b> – Analyze submitted content and generate a verification result.</li>
  <li>🤖 <b>Fake News Detection</b> – Uses Machine Learning-based prediction for content analysis.</li>
  <li>📄 <b>Document Verification</b> – Provides a document-oriented verification interface.</li>
  <li>🔐 <b>User Authentication</b> – User registration and login functionality.</li>
  <li>📊 <b>History Tracking</b> – Keeps track of previous verification activities.</li>
  <li>📱 <b>Responsive Interface</b> – React-based interface for a better user experience.</li>
</ul>

<h2>⚙️ How It Works</h2>

<ol>
  <li>User enters content through the TruthLens AI interface.</li>
  <li>The React frontend sends the request to the FastAPI backend.</li>
  <li>The backend processes the submitted content.</li>
  <li>Machine Learning and NLP-based logic analyzes the content.</li>
  <li>The prediction/verification result is returned to the frontend.</li>
  <li>The result is displayed to the user.</li>
</ol>
